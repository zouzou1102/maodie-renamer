## 一、产品概述

### 1.1 产品定位

一款 **Windows 桌面端免费批量改名工具**，用网络热梗形象「耄耋」（圆头炸毛橘猫）作为产品灵魂，让「批量改文件名 / 文件夹名」这件枯燥的事变得可爱、好玩、有记忆点。

**对标产品：FlyingMouse Format（飞鼠格式）**——它证明了「可爱表情包形象 + 免费 + 简单好用」能让一款工具型软件走红。

### 1.2 产品 Slogan（备选）

- 「耄耋帮你把名字改好。」
- 「文件名字太乱？交给耄耋。」
- 「炸毛，但不炸你的文件名。」

### 1.3 核心价值

| 用户痛点 | 我们的解法 |
| --- | --- |
| 改名软件要钱 / 要 VIP | 完全免费、无广告 |
| 界面陈旧、难用 | 可爱形象 + 极简交互，小白也能用 |
| 批量改名怕改错 | 预览 + 撤销兜底 |
| 下载的文件名一堆广告 / 乱码 | 一键删除 / 替换指定字符 |

## 二、用户画像与使用场景

### 2.1 典型用户故事

**小明（大学生）**：网盘下载了一堆课件，文件名都带「【某某公众号】」前缀。他打开耄耋改名，拖入文件，设置「删除 `【某某公众号】`」，预览无误后点「开改」，1 秒搞定，还顺手给每份课件加了序号。

**小美（行政）**：月底要归档 200 张发票照片，文件名是相机自动编号，她需要统一改成「2026-09-发票-001…」的格式。她用「前缀 + 日期 + 序号」规则一键完成。

### 2.2 核心使用场景

| 场景 | 频率 | 使用功能 |
| --- | --- | --- |
| 去除文件名广告 / 乱码 | 高 | F3 删除字符 |
| 批量替换错误字词 | 高 | F4 替换字符 |
| 统一加序号 / 日期 / 前缀 | 高 | F5 规则化 |
| 整理文件夹名称 | 中 | F2 批量改文件夹 |

## 三、功能详述

### 3.1 文件添加（输入）

- **方式一（P1）**：拖拽文件 / 文件夹到窗口。
- **方式二**：点击「添加文件 / 添加文件夹」按钮，弹出系统选择框。
- 添加后展示文件列表：`原名 → 新名预览`。

### 3.2 改名规则引擎（核心逻辑）

用户可叠加多种规则，规则按顺序执行。规则类型：

| 规则 | 参数 | 示例 |
| --- | --- | --- |
| 删除字符 | 待删字符串 | 删「广告」 → `abc广告.txt` → `abc.txt` |
| 替换字符 | 查找串 + 替换串 + 区分大小写 | `旧` → `新` |
| 添加前缀 | 前缀文本 | `2026_` → `abc.txt` → `2026_abc.txt` |
| 添加后缀 | 后缀文本（在扩展名前） | `_v1` |
| 序号 | 起始值、步长、补零位数 | `001, 002, 003…` |
| 日期 | 格式（YYYY-MM-DD 等） | 插入当前日期 |

### 3.3 预览与执行（P0 安全项）

1. 设置规则后，**实时生成预览**（原名 → 新名）。
2. 预览区高亮「发生变化的字符」。
3. 点击「开始改名」，耄耋进入「改名中」状态（忙碌动画）。
4. 完成后展示成功 / 失败列表，失败项给出原因（如重名冲突）。

### 3.4 撤销机制（P0 安全项）

- 每次改名生成一个**改名映射记录**（原名 ↔ 新名 + 时间戳）。
- 用户可在「撤销」页一键把本次改的名字全部改回。
- 映射记录保存在本地，软件重启后可查。

### 3.5 耄耋形象状态机（产品灵魂）

| 状态 | 触发 | 形象表现（动画） |
| --- | --- | --- |
| 待机 | 打开软件 | 耄耋蹲坐、偶尔眨眼、耳朵微动 |
| 接收文件 | 拖入 / 添加文件 | 耄耋抬头、竖起飞机耳、眼睛盯文件 |
| 改名中 | 点击开始 | 耄耋忙碌、爪子扒拉、冒汗表情 |
| 成功 | 全部完成 | 耄耋得意、扬起下巴 |
| 失败 | 有失败项 | 耄耋炸毛、哈气（还原经典梗） |

> 形象设计原则：**可爱为主、暴躁为辅**，用「炸毛」做幽默反差，避免过度渲染攻击性（规避争议）。

## 四、界面设计说明

### 4.1 整体布局（**横版宽屏 · 左右分栏**）

> 设计原则：**横版宽屏**（宽 > 高），左侧固定为「耄耋形象区 + 主操作按钮」，右侧为「文件列表 + 规则设置」，底部一条状态栏。符合桌面软件的使用习惯，也更能突出形象与列表的横向空间。

```
┌──────────────────────────────────────────────────────────────────────┐
│  耄耋改名                                              ─    □    ✕     │
├──────────────────────┬───────────────────────────────────────────────┤
│                      │  ┌─────────────────────────────────────────┐  │
│    ┌──────────────┐  │  │  文件列表（原名 → 新名预览）             │  │
│    │              │  │  │  ① abc广告.txt   →  abc.txt            │  │
│    │   耄耋形象    │  │  │  ② 【公众号】x.mp4 → x.mp4            │  │
│    │   （动画区）  │  │  │  ③ IMG_0023.JPG  → 2026-001.jpg       │  │
│    └──────────────┘  │  │  …                                      │  │
│    状态：待机中…      │  └─────────────────────────────────────────┘  │
│                      │  ┌─────────────────────────────────────────┐  │
│   [  添加文件  ]      │  │  改名规则设置区                          │  │
│   [ 添加文件夹 ]      │  │  ○ 删除字符    ○ 替换字符    ○ 规则化    │  │
│   [  清空列表  ]      │  │  [ 参数输入框 ]        ☐ 区分大小写      │  │
│                      │  └─────────────────────────────────────────┘  │
│                      │                    [ 开始改名 ]   [ 撤销 ]    │
├──────────────────────┴───────────────────────────────────────────────┤
│  ● 就绪 · 共 12 个文件 · 预览 3 项将发生变化                          │
└──────────────────────────────────────────────────────────────────────┘
```

**分栏说明：**

| 区域 | 位置 | 内容 | 说明 |
| --- | --- | --- | --- |
| 形象区 | 左侧上部 | 耄耋大图 + 状态文字 | 产品灵魂，固定常驻 |
| 操作区 | 左侧下部 | 添加文件 / 文件夹 / 清空 | 输入入口 |
| 列表区 | 右侧上部 | 原名 → 新名预览列表 | 占比最大，滚动展示 |
| 规则区 | 右侧中部 | 删除 / 替换 / 规则化设置 | 核心编辑区 |
| 动作区 | 右侧下部 | 开始改名 / 撤销 | 主操作 |
| 状态栏 | 底部通栏 | 文件数、预览变化数、进度 | 全局反馈 |

> 竖版（上下堆叠）方案已废弃——原因是桌面窗口横宽竖窄，横版分栏能同时看到「形象」与「文件列表」，操作更顺手。

### 4.2 视觉风格

- **主色调**：橘色系（橘猫）+ 奶油白背景，暖色、治愈。
- **字体**：圆润可爱的中文字体（如思源黑体 / 站酷快乐体）。
- **圆角**：大圆角卡片、柔和阴影，Q 弹质感。
- **动效**：形象动画 + 按钮弹性反馈，改名完成有「叮」的音效 / 撒花动效。

## 五、技术方案建议（初稿）

### 5.1 技术选型

| 维度 | 方案 | 理由 |
| --- | --- | --- |
| 桌面框架 | **Electron** 或 **Tauri** | Electron 生态成熟、AI 辅助开发资料多；Tauri 体积更小（<10MB）、更现代 |
| 界面 | HTML + CSS + JS（+ Vue/React） | 方便做可爱动效 |
| 文件操作 | Node.js `fs` / Rust | 本地改名，无需联网 |
| 形象动效 | Lottie / CSS 动画 / GIF 序列帧 | 表情包形象做状态切换 |

> **推荐**：首版用 **Electron + Vue3**（对标 FlyingMouse 同款技术路线，开发资料多，适合小白 + AI 协作）；若追求安装包小，后期可迁移 Tauri。

### 5.2 关键技术点

- 文件名合法性校验（Windows 保留字符 `\ / : * ? " < > |`、路径长度）。
- 重名冲突检测（改名后与已有文件同名时提示）。
- 扩展名保护（默认不改扩展名）。
- 撤销映射记录持久化。
