## 一、项目概述

「耄耋改名」是一款 **Windows 桌面端免费批量改名工具**，核心功能是批量修改文件 / 文件夹名称（删除 / 替换指定字符、按规则重命名），产品灵魂是一只**圆头炸毛的「耄耋」橘猫**形象。

项目的直接灵感来自爆火的 **FlyingMouse Format（飞鼠格式）**——一款用「鼠鼠」表情包做形象、免费离线、支持 80+ 格式转换的工具，在 GitHub 获 613 Star，成为现象级「可爱工具软件」。

**我们要做的不是再造一个格式转换器，而是把「可爱表情包形象 + 免费工具」这套方法论，应用到「批量改名」这个更轻、更高频的细分场景上。**

## 二、市场背景与机会

### 2.1 为什么 FlyingMouse 会火

| 成功因素 | 说明 |
| --- | --- |
| 可爱形象 | 「鼠鼠」表情包击中年轻人审美，有记忆点、想分享 |
| 免费无广告 | 对比满屏 VIP 的同类工具，形成强烈反差 |
| 本地离线 | 隐私安全，无登录、无套路 |
| 简单好用 | 拖入 → 选格式 → 转换，三步搞定 |
| 有梗、可传播 | 「鼠鼠帮你干活」天然适合截图分享、二次传播 |

> **结论**：一款工具软件能否走红，**「可爱形象」是第一杠杆**，功能反而不是最稀缺的。这给我们极大的信心——改名工具的门槛比格式转换更低，更容易快速落地。

### 2.2 我们的机会

- 批量改名是**刚需高频**场景，但市面工具大多收费 / 界面陈旧。
- 用「耄耋」这个**更炸、更有梗**的形象，传播潜力不输「鼠鼠」。
- 改名工具**技术门槛低**，适合小白 + AI 辅助快速开发，可快速验证。

## 五、产品方案摘要

（详见《PRD初稿》，此处只列核心）

- **平台**：Windows 10 / 11 桌面软件。
- **核心功能**：批量改文件 / 文件夹名、删除 / 替换指定字符、按规则重命名。
- **灵魂**：耄耋形象状态机（待机 / 接收 / 改名中 / 成功 / 失败）。
- **安全**：预览 + 撤销兜底。
- **技术**：Electron + Vue3（首版），预留 Tauri 迁移空间。

## 七、风险分析与应对

### 7.1 ⚠️ 最大风险：耄耋表情包版权与舆论

| 风险 | 说明 | 等级 | 应对建议 |
| --- | --- | --- | --- |
| **版权风险** | 网络表情包素材版权归属不明 | 🔴 高 | **已决策：免费非商用、直接使用**；软件标注「禁止商用」、保留换原创能力（属**接受风险**，非消除） |
| **舆论风险** | 「耄耋」梗后有争议关联，品牌商翻过车（品客删视频道歉） | 🟡 中 | 形象「可爱为主、暴躁为辅」，不渲染攻击性；推广保持低调 |
| 改名误操作 | 批量改名不可逆 | 🟢 低（已解决） | 预览 + 撤销已提升为 P0 |
| 与 FlyingMouse 撞脸 | 方法雷同 | 🟢 低 | 差异化：不同形象、不同功能（改名 vs 转换） |

### 7.2 风险应对总策略（v0.2 评审后更新）

经评审决策，本项目**明确采用「直接使用网络耄耋表情包 + 免费非商用」路线**，不再强制要求发布前替换原创形象。风险处置如下：

1. **接受版权风险**：以「个人免费、禁止商用」定位降低被追责动机；软件内明确标注使用范围；架构上保留「一键替换形象资源」能力，若日后出现问题可快速切换。
2. **缓和舆论风险**：形象演绎「可爱为主、暴躁为辅」，把「炸毛哈气」做成幽默彩蛋而非攻击性表达；发布与推广保持低调。
3. **消除操作风险**：预览 + 撤销已确定为 P0 功能，杜绝不可逆误操作。

> ⚠️ **批判性分析 / 决策锁校验**：用户的判断是「不收费就不会侵权」——该判断**部分成立但不够严谨**。著作权侵权不以收费为唯一要件；「鼠鼠」案例未出问题 **不等于** 法律上安全，只是**尚未有人追究**。本立项书**尊重并如实记录**用户「接受该风险」的决策，同时保留上述缓解措施。
> **决策锁状态：风险已接受（Accepted Risk），非「风险已消除」。**
